# 国际化说明

当前前端已接入简体中文语言包，并使用统一的翻译结构组织页面文本。

## 目录说明

- zh-CN.ts: 中文语言包
- i18n.ts: 国际化配置与辅助函数
- index.ts: 语言模块导出

## 使用方式

```ts
import { t } from '@/locales';

const message = t('common.loading');
```

## 设计目标

- 统一界面文案管理
- 支持后续扩展更多语言
- 降低页面文本散落带来的维护成本

## 维护建议

- 新增页面文案时优先放入对应模块的翻译对象中
- 保持 key 命名一致、语义清晰
- 避免在组件中直接硬编码用户可见文本

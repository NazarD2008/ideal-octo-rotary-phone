# LIUMA 客户端绕过模块说明

本文件说明 Android 客户端中 ADB 辅助绕过模块的编译开关和基本使用方式。

## 编译开关

在构建时可选择开启或关闭增强模式：

```bash
# 标准构建
./gradlew assembleRelease

# 开启增强模式
./gradlew assembleRelease -PenableAdbBypass=true
```

## 主要作用

- 提升特定服务的兼容性
- 在受限环境下尝试扩大辅助功能可用范围
- 为兼容性测试提供可切换的实验性行为

## 注意事项

- 该模块属于实验性能力，不保证在所有设备和系统版本上都可用。
- 建议在测试环境中验证后再部署到生产设备。
- 任何绕过行为都应遵循授权、合规与最小权限原则。

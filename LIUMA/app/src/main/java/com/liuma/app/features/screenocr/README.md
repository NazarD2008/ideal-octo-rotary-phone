# 屏幕 OCR 模块说明

该模块基于 Google ML Kit 实现本地 OCR 识别，用于分析屏幕内容并识别潜在的敏感信息。

## 核心能力

- 使用 MediaProjection 捕获屏幕内容
- 本地执行 OCR 识别，减少网络依赖
- 对验证码、邮箱、手机号、银行卡号等内容进行特征识别
- 将识别结果写入本地数据库并支持后续同步

## 典型流程

1. 捕获当前屏幕帧。
2. 对图片执行 OCR。
3. 对识别结果执行规则匹配。
4. 将满足条件的内容记录为结构化结果。

## 设计说明

- 以本地处理为主，尽量减少数据外传。
- 仅保存必要的元数据，避免保存完整屏幕截图。
- 支持按特征类型和时间范围进行查询。

## 合规提醒

- OCR 识别涉及敏感信息处理，请严格控制数据访问范围。
- 仅在授权环境中使用，并确保具备必要的告知与存储政策。
